# SMART on FHIR & Healthcare OAuth 2.0 Integration Lab

Hands-on implementations demonstrating OAuth 2.0 (with PKCE) and SMART on FHIR integration across major healthcare developer sandboxes using command-line and Python tools.

## Sandboxes Included
- [x] **Sandbox 1:** SMART Health IT Reference Sandbox (`launch.smarthealthit.org`)
- [ ] **Sandbox 2:** Epic on FHIR (`open.epic.com`)
- [ ] **Sandbox 3:** Oracle Health / Cerner Developer Sandbox (`code.cerner.com`)
- [ ] **Sandbox 4:** Logica Health Private Sandbox (`sandbox.logicahealth.org`)

## Architecture Overview
- **Protocol:** OAuth 2.0 Authorization Code Flow with PKCE (RFC 7636)
- **Profiles:** SMART App Launch Framework (v1 & v2)
- **Data Standard:** HL7 FHIR Release 4 (R4)
